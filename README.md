# Gurgaon Real Estate Analysis

## Overview
This project analyzes Gurgaon real estate property data using Python, Pandas, and Matplotlib.

## Dataset
- 19,515 property records
- 12 features

## Key Analysis
- Data Cleaning
- Missing Value Analysis
- Duplicate Removal
- Property Price Analysis
- Locality-wise Price Analysis
- BHK-wise Price Analysis
- RERA Approval Impact
- Ready-to-Move vs Under Construction Comparison
- Area vs Price Visualization

## Technologies Used
- Python
- Pandas
- Matplotlib
- VS Code

## Insights
- Identified top localities by average property price
- Compared property prices across different BHK categories
- Evaluated the impact of RERA approval on property prices
- Analyzed property distribution across Gurgaon localities
